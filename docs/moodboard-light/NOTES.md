# Quiet-luxury light — reference notes (small, per mandate)

- **attio-hero.png** — steal: enormous vertical whitespace above/below the hero; one small pill kicker; a single soft blue-tinted gradient wash that only breathes *below* the fold; the product screenshot framed in a rounded hairline card with barely-there shadow. Our galleries get exactly that framed treatment (warm-toned).
- **attio-cards.png / stripe-cards.png** — steal: multi-layer shadow discipline (1px ambient + 12px soft + 40px wash, all under 7% alpha); hairline borders doing most of the depth work; radius consistency (every corner from the same 16–24px family).
- **stripe-hero.png** — steal: body ink is never pure black; secondary text steps down by opacity, not by hue change.
- **area17 / instrument** — captured but rejected as register references (image-led, not card-led); kept only as spacing sanity checks.
